=== Analysis ===
- For B=1 (single-token decode): ANE is 5.0x-25.7x slower than GPU across tested Qwen3.6 projections.
- For B=16 (DFlash block drafting): ANE is 5.6x-15.5x slower than GPU.
- For B=64 (prefill chunk): ANE is 3.2x-18.4x slower than GPU.
- For B=256 (larger prefill): ANE is 13.3x slower than GPU for Q-proj.
- Recommendation: use MLX GPU, not ANE, for these Qwen3.6 prefill/decode linear layers.
- Critical finding: no crossover batch size was observed up to B=256; GPU won every test. Separately, Qwen3.6-35B would need about 40 layers x ~6 linear compiles ≈ 240 total compiles, which exceeds both the conservative 108 budget enforced in mlx-rs and the earlier observed ~119 practical ANE compile budget.
